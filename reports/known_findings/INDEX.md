## 6. How the records map

`index.json` -> `findings[]` fields: `id`, `task`, `mechanism`, `direction`, `affected_versions`, `source`, `url`, `status`, `evidence_type`, `also_reported_by`, `upstream_refs` (issue/PR states fetched), `notes`. Id prefixes: `TOK-` Tokenless, `PM-` Preference Model, `GH-<n>` upstream issue (n in 2323-2450 = maintainer import), `NS-` Northset, `OTHER-` BenchJack/Berkeley RDI. `tasks[]` carries per-task counts, RewardKit/fix PRs, #2086 ratings, PM leaderboard pass counts and narrative. `upstream_items` lists every issue/PR page fetched (state, closing PRs, merge time).
